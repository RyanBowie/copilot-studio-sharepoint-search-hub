# Image and schema provenance

The five department/scope PNG banners are original geometric artwork generated by
`scripts/build-rich-card-assets.py`. They contain no Microsoft logos. Their
release license remains an owner decision; this notice does not choose a license
for the repository.

`assets/sharepoint-48.png` is the unmodified Microsoft SharePoint product icon
provided by Microsoft's Fabric asset CDN. Microsoft retains all rights. It is
**not** covered by any future project license. Its source URL and SHA-256 are in
`assets.json`. Use is subject to the
[Microsoft Fabric Assets License Agreement](https://aka.ms/fluentui-assets-license)
and Microsoft's trademark/visual guidelines.

This implementation labels the icon **Microsoft SharePoint** to illustrate the
Microsoft integration, separately from the original scope artwork. It is not
the agent's logo, is not combined into the banners, is not modified, and does
not imply Microsoft endorsement. The contextual card contains no actions.
Do not repurpose the icon as decorative agent branding. Owners and downstream
users must review the applicable license, visual guidelines and rights before
redistributing or releasing their implementation.

`schema/adaptive-card-1.5.json` comes from Microsoft's AdaptiveCards repository.
Its upstream MIT license is reproduced in `schema/LICENSE`; this license applies
to that upstream material, not the SharePoint icon or the whole repository.

The asset generator only downloads the exact official URLs recorded in its
source. Once `assets.json` exists, an upstream hash change fails closed for
review. Ordinary flow builds use local assets and make no network requests.
